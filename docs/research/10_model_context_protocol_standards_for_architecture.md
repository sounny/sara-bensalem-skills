MCP Domain-Specific Tool Schemas for Architecture
Model Context Protocol (MCP) servers extend standardized JSON-RPC primitives to spatial and architectural design, allowing host environments like Claude Desktop and Cursor to interface directly with geometry kernels, CAD pipelines, and structural analysis libraries.  
arXiv

Key Architectural Tool Schemas

audit_pdf_portfolio: Ingests multi-page architectural submissions via structured JSON payloads, evaluating layout hierarchy, scale bar accuracy, and typographic consistency through integrated vision models.

generate_parametric_layout: Maps programmatic adjacency matrices and spatial constraints to parametric vector formats (such as DXF, SVG, or IFC), outputting precise coordinate arrays for walls, cores, and circulation paths.

validate_1_20_assembly: Cross-references high-detail 1:20 construction drawings against material database specifications, checking thermal insulation continuity, water-proofing layers, and structural connection tolerances.

evaluate_constructibility: Assesses physical buildability by parsing weight distributions, prefabrication shipping limits, modular grid repeatability, and fastener accessibility, replacing code-compilation checks with real-world material logic.

Frontier of Agentic Spatial Tooling
The current frontier shifts AI away from software code generation toward multi-agent spatial orchestration. Using hybrid MCP architectures, the client maintains stateful session context while isolated local servers execute heavy geometric kinematics, finite element analysis, and zoning code validation. This decoupling bridges the gap between abstract generative text and physical constructibility, transforming AI into an active partner for tectonic design.

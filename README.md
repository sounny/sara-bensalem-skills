## 🏛️ Philosophy: Spatial Design Products, Not Web/Software UI

**Sara Bensalem Design Skills** is an open agentic studio and Model Context Protocol (MCP) server engineered specifically for **physical, architectural, and spatial design deliverables**.

While modern AI coding tools and Python/SVG/Typst engines power the generation under the hood, **these skills are not for building software UIs or web apps**. ## 🚀 The Flagship Skill: Spatial Portfolio Architecture & Curation

Hiring directors at premier international studios (*Foster + Partners*, *BIG*, *Gensler*, *Snøhetta*, *Dar Al-Handasah*, Parisian interior ateliers) review between 200 and 600 applications per opening in **15 to 30 seconds**. 

**The 4 Fatal Traps Eliminated by This Skill**:
1. **The Render Trap (75% of rejections)**: Saturated Lumion/Enscape visuals with zero constructive reality (no wall sections or structural cotations). *Diagnosis: "Can render, cannot build."*
2. **The Wall-of-Text Trap**: Exhaustive essays that reviewers immediately skip.
3. **The Micro-Font Trap**: Uncalibrated 4pt CAD annotations illegible on standard monitors.
4. **The Monotonous Grid Trap**: Identical 4-box grids on every spread with no breathing room or white space.

### The 10 Field-Tested Layout Archetypes
1. **The Swiss Editorial Landscape** (Junior to Intermediate Agency Architects — *Benchmark: Thibault Chrétien*)
2. **The Technical Office Working Set** (Execution & Site Architects — *Benchmark: Salma Sameh*)
3. **The French Luxury Minimalist Book** (Interior Architects & Decorators — *Benchmark: Orlane Bizeray*)
4. **The Phenomenological Storyboard** (Cultural & Narrative Architects — *Benchmark: Neha George*)
5. **The Feminist Urbanist & Social Researcher** (Civic & Master Planners — *Benchmark: Aishwarya Bagwe*)
6. **The Vernacular & Ecological Monograph** (Tropical & Heritage Practices — *Benchmark: Alif Ahammed*)
7. **The Regenerative Environmental Systems** (Resilience Consultancies — *Benchmark: Nayera Sabet*)
8. **The Commercial Interior Specifier** (Retail & Hospitality Designers — *Benchmark: Loan Lubrano*)
9. **The Multi-Scale Infrastructure Architect** (Transit & Large Scale — *Benchmark: Raden Ontoseno*)
10. **The Industrial Housing & Net-Zero BIM** (Affordable Housing & BIM — *Benchmark: Sarfaraz Shaik*)

### The 5-Act Spatial Case Study Structure
- **Act I: The Hook & Project Passport** (Spread 1 Left: Title, Typology, Software, 2-sentence executive premise)
- **Act II: The Contextual Conflict & Research** (Spread 1 Right: Site constraints, climatic solar/wind paths)
- **Act III: Spatial Strategy & Volumetric Evolution** (Spread 2 Left: 3-step massing diagrams or exploded axon)
- **Act IV: Constructive Proof (Anti-Trap)** (Spread 2 Right & 3 Left: Scaled 1:50 plans, 1:10 wall sections)
- **Act V: Sensory Atmosphere & Outcome** (Spread 3 Right: Muted render, material triptych, daylight study)

## ⚡ Model Context Protocol (MCP) Integration

Equip your AI assistants (Claude Desktop, Cursor, Antigravity) with Sara Bensalem's design skills via the bundled stdio JSON-RPC MCP server.

### Available MCP Tools
- `list_sara_skills`: Returns all active and upcoming skills in the studio.
- `audit_portfolio`: Audits a PDF portfolio against the 100-point rubric and checks for file size, aspect ratio, text density, and render traps.
- `recommend_archetype`: Matches candidates to their ideal layout archetype based on discipline and target firms.
- `generate_5act_structure`: Drafts a tailored 5-act case study structure for any architectural project.
- `get_100pt_rubric`: Returns the quantitative 100-point rubric breakdown across the 6 core pillars.

### Claude Desktop Configuration
Add to your `claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "sara-bensalem-design-skills": {
      "command": "python",
      "args": [
        "g:\\My Drive\\Projects\\sara-bensalem-skills\\mcp-server\\server.py"
      ]
    }
  }
}
```

### Antigravity / Cursor Configuration
Add to your project's `.antigravity/mcp.json` or `.cursor/mcp.json`:
```json
{
  "mcpServers": {
    "sara-bensalem-skills": {
      "command": "python",
      "args": [
        "${workspaceFolder}/mcp-server/server.py"
      ]
    }
  }
}
```
